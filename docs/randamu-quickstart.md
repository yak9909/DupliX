# randamu 最初の版の使い方

3D レイヤーにエフェクト「randamu」を 1 つ掛けると、そのレイヤーのコピーが n 枚、ランダムな位置・回転・大きさ・不透明度で並びます。コピーは After Effects 自身の 3D 描画で描かれるので、ライト・影・被写界深度・モーションブラー・調整レイヤー・ほかのレイヤーとの前後や交差は、本物の複製レイヤーを置いたときと同じ絵になります。

## 入れ方

1. After Effects を閉じます。ビルドで `dev_plugins\randamu.aex` を置き換えるときも、AE を閉じてから行ってください（AE が開いている間はファイルが使用中です）。
2. プラグインのフォルダーは、`MediaCore\randamu_dev` から `randamu\dev_plugins` へのジャンクションとして作成済みです。追加の作業は要りません。
3. After Effects 2025 を起動します。エフェクトのメニューの「randamu」>「randamu」に出ます。

## 使い方

1. コンプのレンダラーが「クラシック 3D」であることを確かめます。
2. 散らしたいレイヤーを 3D レイヤーにします。
3. そのレイヤーに「randamu」を掛けます。既定では 10 枚のコピーが、元の位置のまわり ±200 px に散らばります。
4. エフェクトコントロールの「状態」に「準備できています」と出ていれば動いています（「状態」のチェックボックスは表示用で、操作しても何も起きません）。

元のレイヤーそのものは描かれず、コピーだけが描かれます。元の位置にも 1 枚ほしいときは「1 枚目は元の位置」をオンにします。

## パラメータ

| 名前 | 意味 |
|---|---|
| 状態 | 動いているかどうかの表示（下の「困ったとき」） |
| コピー数 | コピーの枚数。0 ならレイヤーは何も描かれません。上限はありませんが、多いと重くなります |
| 乱数の種 | 並びを変えたいときに変えます。同じ値なら、いつ開いても同じ並びです |
| 位置の範囲 X / Y / Z | レイヤーの座標で、アンカーポイントを中心に ±範囲のどこかに置きます |
| 回転の範囲 X / Y / Z | アンカーポイントを中心に、各軸 ±範囲（度）のどこかまで回します |
| 拡大縮小の最小 / 最大 | 縦横同じ比率で、最小〜最大（%）のどこかの大きさにします |
| 不透明度の最小 / 最大 | 最小〜最大（%）のどこかの不透明度にします。レイヤー自身の不透明度に掛け合わせます |
| 1 枚目は元の位置 | オンにすると、1 枚目だけは散らさず元の位置・向き・大きさのままにします |

レイヤー自身の位置・回転・拡大縮小・親子付けは、コピー全体に効きます（コピーはレイヤーの座標で散らばるので、レイヤーを動かすとコピーの群れごと動きます）。パラメータにはキーフレームも付けられます。

## 分かっている制限

- **2D レイヤーには使えません。** 「状態」に「3D レイヤーにしてください」と出て、元のレイヤーがそのまま描かれます。
- **時間のずらし（コピーごとに再生位置をずらす）はまだありません。**
- **枚数が多いと重くなります。** 目安は 2500 枚で 1 フレーム約 20 秒です。
- **After Effects 2025（25.6）の Windows 版でしか動きません。** AE の内部の関数を差し替えて動かしているためです。ほかの版では「この AE の版ではコピーを作れません」と出て、元のレイヤーがそのまま描かれます（AE は落ちません）。
- GPU（プロジェクト設定の「Mercury GPU 高速処理」）に対応しています。CUDA で、CPU と画素単位で同じ絵になることを確かめました。OpenCL と DirectX 12 の経路もありますが、試せる環境がなく未確認です。なお、GPU で動くのはこのエフェクト自身の処理だけです。コピーの 3D 描画はクラシック 3D レンダラーが CPU で行うので、全体の速さはほとんど変わりません。
- クラシック 3D レンダラーだけを対象にしています。Advanced 3D／Cinema 4D レンダラーでの見た目は確かめていません。
- 自動試験で確かめたのは、書き出し（aerender、マルチフレームレンダリングのオン・オフ）、保存して開き直したプロジェクト、スクリプトからの時間の移動・パラメータ変更・取り消し・エフェクトのオン／オフです。**ビューアーでのスクラブやプレビューを手で操作したときの動きは、自動では確かめられていません。** 止まる、絵が古いまま変わらない、キーフレームの途中で書き出しと違う絵になる、といったことがあれば教えてください。

## 困ったとき

「状態」の表示:

| 表示 | 意味 |
|---|---|
| 準備できています | 正常 |
| 3D レイヤーにしてください | レイヤーが 2D |
| エフェクトがオフです | エフェクトのスイッチ（fx）がオフ |
| この AE の版ではコピーを作れません | AE の版が違い、差し替えができなかった |
| 状態を確認できません | 上のどれにも当たらない。ログを取ってください |

ログの取り方: 環境変数 `RANDAMU_LOG` にログファイルのパスを入れて AE を起動すると、そのファイルにプラグインの動きが書かれます。PowerShell なら次のとおりです。

```powershell
$env:RANDAMU_LOG = "C:\temp\randamu.log"
& "C:\Program Files\Adobe\Adobe After Effects 2025\Support Files\AfterFX.exe"
```

AE が止まった・落ちたときは、このログと、そのとき何をしていたかを送ってください。ログの最初に `hooks: installed` と出ていれば、差し替えはできています。
