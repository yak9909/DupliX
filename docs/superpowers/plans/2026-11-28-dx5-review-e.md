## Global Constraints

- `src/dxg5` は AE・Win32 のヘッダーを含まない。`src/dxg5` の .cpp は名前の頭に `dx5_` を付ける（obj の名前がぶつかる）。v2 は `src/graph` と `src/dxg5` の両方をコンパイルする。
- 演算のノードの保存の種類は `math`・`vmath`・`compare`・`boolmath`・`rotate` の 5 つ、演算子は `op=`（v5 6.2・7）。コードでは演算子ごとの名前（`math_add(a, b)`）。P1.5 で保存した `math_add` などの種類は読むときに直す。
- 効かない線（隠した入力・型の合わない線）はコードで `_` を付けた名前の引数（`math_sin(x, _b: y)`）。読み取りは型を確かめない（v5 6.2）。
- 入力欄が受け付けるのは定数と定数だけの式（v5 8.3）。
- Expression ノード: 行は `出口 = 式`、名前のない 1 行は出口 `value`、`_` で始まる行は出口にしない。その場で読む名前は決まった一覧（v5 8.3）。名前付きの属性は `attr("ix")`（v5 16 の 4）。式は確定（Ctrl+Enter・欄の外へ）で効く。なくなったソケットの線は外す。塩のない `random()` に塩を付けて文字に書き戻す。
- 値のノードの key は書き出しが付け直してよい（v5 11）。それ以外の key は変わらない。
- グループ: 出口が複数なら `return (名前: 値, …)`、使う所は `r.名前`。外の変数は読めない。組み込みと同じ名前は誤り。再帰は誤り。`structural` の印は省いてよく、書き出しはいつも書く。利用者のグループの保存の版は 0（v5 12.1・7）。
- マクロは「使われているか」と名前だけ。解放の操作は作らない。Macros の欄は使われているものを出し、名前付きの使われていないものは「unused」の見出しに畳む（v5 4.4）。
- エディターの書き込みは `ed::Commit`（取り消し 1 回分）。利用者への文言は英語。
- 作業ツリーの改行コードだけの変更（`src/core`・`src/gpu` など 13 ファイル）は触らない。`git add` はファイルを指定する。

## Review Focus

1. **P1.5 で保存したグラフ（`math_add` の種類、出口 1 つの Expression）と版 1 のグラフ（`tests/ae/fixtures/dx2_p1.aep`）を開く**: 同じ要素・同じ ID。→ Task 1 の `math_legacy_types_read` と Task 7 の `run_dx2_p1_fixture.ps1`。
2. **Expression の式を打ち直して、つながっていた入口の名前を変える・消す**: 名前の残る入口の線は残り、消えた入口の線だけ外れ、取り消し 1 回で戻る。→ Task 2 の `formula_keeps_wires_by_name`。
3. **演算子を `add` → `sin` → `add` と替える**: 2 つめの入力の線が戻って効く。往復のコードでも消えない。→ Task 1 の `math_hidden_input_wire_kept` と Task 3 の `print_disabled_arg_round_trip`。
4. **式の中の打ち間違い（`indx`）**: ノード表示では入口が増える（誤りにしない）。コード・積み重ね表示では行と列つきの誤り。→ Task 2 の `formula_unknown_name_is_input` と Task 3 の `lower_expr_block_unknown_name_rejected`。
5. **グループが自分を呼ぶ・組み込みと同じ名前**: 読み取りが行と列つきで拒み、グラフは変わらない。→ Task 4 の `group_recursion_rejected`・`group_name_clash_rejected`。
