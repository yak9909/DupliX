# 開発記録 2026-11-25（高速モードの作り直し）

計画: `docs/superpowers/plans/2026-11-25-fast-mode-plugin.md`。設計上の決定は設計書 12.13 の末尾。

## 1. Task 1: 実現性の確認（実験、コードは消した）

実験の分岐（環境変数 `RANDAMU_PROBE_TRANSFER=1`）を一時的に入れ、見えないデスクトップの AE で確かめた。分岐と実験のスクリプトは消した（`git checkout src/effect/randamu.cpp`）。

| 確かめたこと | 結果 |
|---|---|
| スクリプトの `fx.property(15).setValue(1)`（「高速モード」に `PF_ParamFlag_SUPERVISE` を付けたとき）で `PF_Cmd_USER_CHANGED_PARAM` が来るか | **来る**（`param_index` 15）。書き写しは自動の試験で確かめられる |
| `USER_CHANGED_PARAM` の中で、`params[]` の値の書き換え＋`PF_ChangeFlag_CHANGED_VALUE` | 効く（位置の範囲 X が 200 → 123） |
| 同じ中で AEGP: `AEGP_StartUndoGroup` → キーフレームの削除（`AEGP_DeleteKeyframe`、2 個）→ エクスプレッションをオフ（`AEGP_SetExpressionState`）→ `AEGP_SetStreamValue`（位置・Y 回転・方向）→ `AEGP_SetLayerParent(L, nullptr)` → `AEGP_SetLayerFlag(3D, FALSE)` → `AEGP_EndUndoGroup` | すべてエラー 0。AE は止まらない |
| 取り消し（`app.executeCommand(16)`）1 回 | **パラメータの書き換えと AEGP の変更が全部戻る**（3D・親・キーフレーム 2 個・位置・Y 回転・エクスプレッション・位置の範囲 X・高速モードのチェック）。2 回目の取り消しはエフェクトの追加を取り消した |
| 2D レイヤーのエフェクトで `AEGP_GetEffectCameraMatrix` | コンプのカメラを返す（カメラの位置を (120, 60, −700) にすると、そのまま返る）。dist 555.556（400×300 の既定のカメラ） |
| 座標の原点 | `AEGP_GetLayerToWorldXform` はコンプ px（左上が原点）。2D レイヤー（位置 (200,150)、アンカー (40,30)）の平行移動は (160, 120, 0)。つまり計画の `V = T(−A)·T(幅/2, 高さ/2, 0)` で正しい |
| 2D レイヤーの出力を、負の原点のコンプ大（`max_result_rect` = (A − 中央) からコンプの大きさ）にする | 効く。出力の全面が画面を覆い、入力はレイヤーの位置に出る。アンカーを (10,10) に変えても全面を覆う |
