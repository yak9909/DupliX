この文書は、ハリボテ（`docs/design/2026-11-27-v2-effect-controls.md`）を試した利用者の要望を、実装前の要求としてまとめたもの。

## 1. 複数の Emitter（取り下げ、11/27 夜）

粒子と複製を分ける決定により、この要望は DupliX 2 では扱わない（0 節）。代わりの「時間で出現」は 7 節。以下は当時の要望の記録。

- Emitter を複数持てる（例: 画面の左右から別々に湧く、地面から湧く粒と空から降る粒を 1 つのエフェクトで）。
- Emitter ごとに、発生元の形（Shape）・発生の設定（時刻・量・寿命・初速など）を持つ。
- 未決: Emitter ごとに粒の数（Count）を分けるか、全体の Count を配分するか。Emitter ごとに Source（素材）を変えられるか。

## 2. Morph を続けてつなぐ

- Polar → Sphere → Grid のように、3 つ以上の形を順になめらかに変化させたい。
- 1 本のキーフレームで「いまどの形の間にいるか」を動かせると分かりやすい。
- コピーごとに変化の時刻をずらす（左から順に、ランダムな順に）は v2 と同じく欲しい。
- （取り下げ: Emitter をやめたため。「散らばった形から格子へ」は Scatter の Shape から Grid の Shape への Morph で作る）

## 3. 独自エディター（案 C）

- Effect Controls には入口（よく使う設定）と、使っている枠だけを出す。細かい組み立て（枠の追加・削除・並べ替え・複製、Morph の順番、グラデーションの編集など）はエディターで行う。
- エディターで作ったものも、値は AE のパラメータなので、タイムラインでキーフレームを打てる。
- 自前で描く（Web の画面は使わない）。未決: 入り口を AE のパネルにするか、ボタンで開く別の窓にするか。

## 4. 配置の範囲とバッファ

### 4.1 バッファの自動拡張

- コピーがレイヤーの範囲（例: Grid Size をレイヤーより大きくした）からはみ出したとき、描く範囲（出力のバッファ）を自動で広げるオプションが欲しい。
- オフなら今どおりレイヤーの範囲で切れる。
- 未決: 広げる上限、余白（ぼかしや影のため）。

### 4.2 大きさを変えるときの中心

- Grid Size などで配置の大きさを変えるとき、どこを動かない点（中心）にするかを選びたい。
  - 配置の中心（今の動き）
  - 何らかの要素を中心にする: 例として、最初のコピー、最後のコピー、指定した番号のコピー、配置の角（左上など）、任意の点（ヌルなどのレイヤーにつなげる）
- 未決: Polar・Sphere・Path でも同じ選択肢にするか（Polar の「中心」は円の中心で自然に決まる）。

## 5. 見た目（透明度・色・合成）

### 5.1 透明度と色の合成

- コピーの透明度・色を変えられる（今の v2 では Modifier の Opacity・Tint だけ）。
- コピー同士の合成の方法（描画モード）を選べる: 通常、加算、スクリーン、乗算 など。
- 未決: 元の素材の色との混ぜ方（色を置き換える／掛ける／色相だけ変える）。

### 5.2 グラデーション

- コピーにグラデーションで色を付けたい（番号順、A・B の位置、中心からの距離、Age などに沿って）。
- **色の補間の方法を複数用意する**: 例として RGB、リニア RGB、HSV / HSL（色相を近回り・遠回り）、Lab、OKLab、OKLCH、段階（補間しない）。
- 色の止め（ストップ）を複数置けて、位置と色を動かせる（キーフレームも）。

### 5.3 Order に沿って重ねていく

- Order（番号順・A・B・ランダム・距離・Age など、Stagger と同じ並び）の順に、
  - 透明度を掛け合わせていく（例: 1 つ進むごとに × 0.8。エコーのように奥ほど薄く）
  - 色を掛け合わせていく（1 つ進むごとに同じ色を掛ける）
  - 色を変えていく（1 つ進むごとに色相を回す、グラデーションを 1 段ずつ進む）
- 時刻と要素の番号だけで決まる（前のフレームを使わない、v2 の 0 節の原則を守る）。

## 7. 時間で出現する（11/27 夜）

- 最初から並んでいるコピーが、時間とともに出現する（または消える）。
- 出る順番には Order（番号順・A・B・ランダム・距離など）が効く。
- コピーの数・位置・順番は最初から決まっていて、時間で変わるのは見え方だけ（順に「生まれて」飛んでいく粒子ではない）。

## 6. ほかに今までに決まった・出た要望（再掲）

- 入口はシンプル、奥で細かく（v2）。Custom UI で分かりやすく。
- 複数の画像（コンプのレイヤー）を Source にする。最大 8（ハリボテで実装済み）。
- 今の DupliX（3D Layers・Fast (2D)・軽量化）は別のエフェクトとして残る。DupliX 2 がそれをどう取り込むかは未決。
