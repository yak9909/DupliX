# 複製プラグイン 設計案 v4（シンセ風: グラフとマクロ）

- 作成日：2026-11-27
- 位置付け：v3（`複製プラグイン設計案_v3.md`、枠とエディターの混合＝案 C）を置き換える。利用者が「シンセ風」を選んだ（11/27 夜）。v3 の考え方のうち、Order（q と段 s）、量の掛け方、色と透明度の順番、Pivot、Canvas、3D Layers と Fast、時間で出現は、ここに引き継ぐ。
- 入力: `2026-11-27-wanted-features.md`（要望と決定）、他の人の助言（配置を t の関数として見る、点の並びを返す配置、「ジオメトリ → ジオメトリの並び」の連鎖、0 秒の時点の粒子＝配置、シンセの LFO / ENV、ゲームエンジン、Cavalry の Distribution の一覧）
- 変えない原則：**すべての値は「時刻と要素番号だけで決まる」**（前のフレームの結果を使わない。AE は順不同・同時にフレームを求めるため）
- AE 実機での確認が要る点には「要検証」と書いた

---

## 0. 結論

1. **中身はすべて独自エディターの中のグラフ（つなぎ図）に持つ。** 配置・変形・揺れ・時間の変化・色のつなぎ方は、エディターでしか触らない。グラフは Arbitrary Data 1 個（**グラフデータ**）に入れる。
2. **AE に出すのは少しのつまみ（マクロ）だけ。** Macro 1〜32（数値）・Color Macro 1〜8・Point Macro 1〜8 を Effect Controls に出し、キーフレームとエクスプレッションはここに打つ。エディターの中で、1 つのマクロを好きな数の値に、好きな深さでつなぐ（シンセのつまみと同じ）。
3. **中の値を時間で動かすのは、エディターの中の Modulator（LFO・ENV など）。** AE のキーフレームで動かしたい値は「マクロに出す」ボタンでマクロにつなぐ。
4. **配置（Generator）は 2 種類。** t（と s, w）で位置が決まるもの（線・円・格子・球・パスなど）と、点の並びを返すもの（多面体・マスクの頂点・レイヤーのアルファに敷き詰め など）。**Operator** が「ジオメトリ → ジオメトリ」を連鎖させる（入れ子・Morph・絞り込み・並べ替え）。
5. **Emitter は「配置 ＋ 時間のずらし ＋ 出た後の動き」の組み合わせとして作る。** 前のフレームを使わずに、粒子に近い見た目（湧き出し・爆発・重力・乱れ）を作る（5 節）。順に生まれる専用の仕組みは作らない。
6. 描き方は 3D Layers と Fast の 2 つ（v3 の 7.3 節を引き継ぐ）。エディターは自前で描き、Web の画面は使わない。

## 1. AE の側（Effect Controls）と、エディターの側

### 1.1 Effect Controls（固定のパラメータ）

| 行 | 中身 |
|---|---|
| Overview | Custom UI: 配置の図・要約・**Open Editor** ボタン・使っているマクロの一覧 |
| Render Mode | 3D Layers / Fast（既定 Fast、時間で変えない） |
| Macros | Macro 1〜32（数値）、Color Macro 1〜8、Point Macro 1〜8（3D の点。ヌルをピックウィップでつなぐ） |
| Layers | Layer 1〜8（AE のレイヤーを選ぶ。複製元・マップ・アルファの敷き詰めの入力。ハリボテの Sources を一般化） |
| Graph | グラフデータ（Arbitrary Data、Effect Controls には出さない。`CANNOT_TIME_VARY`） |
| Random Seed | 全体の乱数の種（よく触るので外に出す） |

- 合計は約 70 個。v3 の約 730 個から大きく減る（Effect Controls が軽くなり、パラメータの数の上限で悩まない）。
- **使っていないマクロ・レイヤーの行は隠す。** 隠す可能性のある行に角度パラメータを使わない（v3 の 1.2 節。ダイヤルが残る）。
- **マクロの名前:** エディターで付けた名前（例: 「Spread」）を `PF_UpdateParamUI` で Effect Controls の表示名にする。この変更は見た目だけで保存されないので、名前はグラフデータに持ち、UPDATE_PARAMS_UI のたびに付け直す。タイムラインの表示名も変わるかは要検証。
  - エクスプレッションは名前ではなくマッチ名（`DupliX2-00NN`）で参照するよう案内する（名前は付け替えられるため）。ピックウィップが表示名で書くかは要検証。
  - `PF_UpdateParamUI` を呼べるのは USER_CHANGED_PARAM と UPDATE_PARAMS_UI のときだけ（SDK のヘッダー）。タイムラインの表示名は「Macro 7」のままと見込む（推測）。そのときは Overview のマクロの一覧で、名前と番号の対応を見せる。
- マクロの範囲: 数値マクロの値の範囲は −1,000,000〜1,000,000。スライダーの範囲（既定 0〜100）は、エディターで決めた範囲を `PF_UpdateParamUI` で付け直す（スライダーの範囲は変えられる項目）。エディターで「マクロの値を、つなぎ先の何から何に当てるか」を決める（つなぎ先ごとに Min / Max / カーブ）。
- **つなぎ先を替えるときの警告:** キーかエクスプレッションのあるマクロのつなぎ先を替えると、打ってあるキーの意味が変わる。エディターは替える前に警告する。

### 1.2 エディター（グラフの編集）

- 自前で描く（Web の画面は使わない、利用者の決定）。入り口は Open Editor ボタンの別の窓、または AE のパネル（P0 で決める）。
- グラフデータを書き換えるたびに、AE の取り消し（Ctrl+Z）1 回分にする。
- エディターがないと中身を変えられない（v3 の「Effect Controls だけでも使える」はなくなる）。代わりに、**プリセット**（よく使うグラフ: 格子・円・螺旋・湧き出し・爆発・エコー など）を Overview から選べるようにし、選んだ後はマクロだけで調整できるようにする。
- **エフェクトを付けた直後のグラフ:** 格子 5 × 5 のプリセット。マクロは Count・Spacing・Copy Scale の 3 つが名前付きでつながっている（何も触らなくても絵が出て、マクロだけで調整できる）。
- **利用者のプリセット:** エディターからグラフをファイル（.dx2graph）に保存・読み込みできる。AE のアニメーションプリセット（.ffx）にもグラフデータは入るはず（Arbitrary Data もエフェクトの値として保存されるため。要検証）。

## 2. グラフ（つなぎ図）

```
[Generator] ─→ [Operator] ─→ … ─→ [Output]
                   ↑ 数値の入力には Modulator / Macro をつなげる（深さ付き）
```

- 流れるもの: **ジオメトリ** ＝ 要素の並び。各要素は次を持つ。
  - **ID**（固定の番号。2.4 節）と、並びの中の位置（表示用の番号）
  - 位置、向き（T/N/B）、q と段 s（2.4 節）
  - 属性: 大きさ・回転・透明度・色・時間・Source 番号・開始時刻 t_i・**Weight**（効き目、0〜1、既定 1）・**Visible**（描くか）
- ノードの数値の入力（例: Grid Size X）は、そのままの値か、Modulator・Macro をつないだ値（**値 ＝ 基準 ＋ Σ 深さ × Modulator の出力**）。属性を変える Modify は、この値を v3 の 5.0 節の掛け方（足す・(1＋値) を掛ける・Tint を混ぜる）で属性に効かせる。量の掛け方の定義はこの 1 つだけ。
- **構造の入力**（要素の数や並びを決めるもの: Count、Sides、Instance の上限、Generator の種類、Morph の合わせ方、選択肢の類）は、定数か Macro だけをつなげる。要素ごとの Modulator（LFO・Stagger など）はつなげない（エディターが受け付けない）。Macro にキーを打てば要素の数は時間で変わる。3D Layers がフレームごとの数の変化に耐えるかは要検証（今の DupliX の Copies はキーを打てるので、同じ扱いの見込み）。v3 の 1.3 節「時間で変えない選択」は、Generator の種類などの選択肢に引き継ぐ（Macro もつなげない）。
- グラフは**毎フレーム、時刻 t と要素番号だけから**計算する。前のフレームの結果は使わない。
- 評価は AE の PreRender で行い、結果（要素ごとの位置・属性）を描き方（3D Layers / Fast）に渡す。
- **ピクセルを読む入力（Layer Alpha・Map）:** SmartFX では、レイヤーのピクセルを読めるのは SmartRender の中だけで、PreRender では範囲しか分からない。
  - Layer Alpha（敷き詰め）は **Sample Time**（読む時刻、時間で変えない構造の入力）を持ち、一度読んだ点の並びをキャッシュする（キーはレイヤー・時刻・そのレイヤーの変化の状態）。
  - Map は SmartRender で評価する。Map が位置を動かすグラフでは、PreRender で Canvas Auto の範囲を正確には出せないので、Map の深さの最大で広げた保守的な範囲にする。
  - どちらも、キャッシュがまだないフレームでは、Canvas は保守的な範囲（レイヤーの範囲 ＋ 深さの最大）にする。

### 2.1 Generator（配置を作る）

| 種類 | Generator | 位置の決め方 |
|---|---|---|
| t で決まる（線） | Line、Circle（多角形も Sides で）、Spiral、Rose、Path（AE のマスクを読む） | 1 つの値 t（0〜1） |
| t, s で決まる（面） | Grid、Polar（同心円・放射）、Sphere、Torus、Fibonacci（円盤・球） | 2 つの値 |
| t, s, w（立体） | Grid 3D、Sphere の殻 | 3 つの値 |
| 点の並び | Polyhedron（正多面体の頂点・辺の中点・面の中心）、Mask Vertices、Layer Alpha（レイヤーのアルファに敷き詰め、Cavalry の Voxelize）、Scatter（箱・円盤・球の中に、低食い違い列）、Point（全部を同じ場所に） | 番号だけ |

- t で決まるものは「t をずらす」（Flow、v2 の 3 節）で線や面に沿って流せる。点の並びには Flow を使えない（エディターで灰色）。
- 数の決め方: 「t で決まる」ものは Count（とその向きの数）、「点の並び」は Generator が数を決める（多面体の頂点数など）か Count で上限を切る。

### 2.2 Operator（ジオメトリ → ジオメトリ）

| Operator | 働き |
|---|---|
| Transform | 全体を動かす・回す・広げる（Pivot、v3 の 2.3 節の定義。Pivot はこのノードの設定） |
| Flow | t で決まる配置の t（と s, w）をずらしてループさせる（v2 の 3 節: Offset・Speed・Speed Variance・Step・Boundary・Edge Fade）。点の並びには使えない |
| Instance（入れ子） | 入力の各要素の場所に、別の Generator の形を置く（「ジオメトリ → ジオメトリの並び」の連鎖。格子の各点に円 など）。数は掛け算になるので上限を持つ |
| Morph | 2 つ以上の入力を Morph の値で補間（1.5 なら 1 番目と 2 番目の中間）。要素数が違うときの合わせ方と、補間する属性は 2.5 節 |
| Merge | 複数の入力を並べてつなぐ |
| Mask | 範囲（レイヤーのアルファ、球・箱、番号の範囲、N 個おき）で、要素の **Weight**（効き目）か **Visible**（描くか）を決める。**要素を並びから取り除かない**（番号や順番が時間で飛ばないように） |
| Sort / Shuffle | 並びの順（q と段 s）を付け替える（番号順・X/Y/Z・距離・ランダム・逆順。Cavalry の Sort / Shuffle） |
| Modify | 要素の属性を変える（位置・回転・大きさ・透明度・色・時間・Source 番号）。効き目は要素の Weight を掛ける（v3 の「Mask で効き目を絞る」はこの形） |
| Source | 各要素が使う Layer（複製元）を決める（v3 の Assign: Sequential / Random / By Order） |
| Motion | 開始時刻 t_i からの経過で動かす（5 節） |
| Appearance | 色・グラデーション・Cascade・Color Blend（v3 の 6 節） |
| Output | 最後の 1 つ。Copy Scale（コピーの大きさの基準）、Blend Mode・Composite（v3 の 6.1 節）、Canvas（v3 の 7.2 節）、Billboard・Depth |

### 2.4 ID と並びの順（番号を振り直しても飛ばないように）

- **ID:** 各要素は、生まれた経路で決まる固定の ID を持つ。Generator は (Generator の番号, 要素の番号)、Merge は (入力の番号, 元の ID)、Instance は (親の ID, 子の番号)。ID はハッシュにして持つ。
- **乱数・Jitter・Random の Order は ID から作る**。並びの位置や数が変わっても、同じ要素の乱数は変わらない。
- **q と段 s:**

| Order | q | 段 s |
|---|---|---|
| Index | 並びの位置 ÷ (数 − 1) | 並びの位置 |
| A / B / C（t で決まる配置） | その Generator の (a,b,c) から（v3 の 5.1 節） | a など |
| Parent / Child（Instance の後） | 親の並びの位置・子の番号から | 親・子の番号 |
| Random | hash(ID, Seed) | なし |
| Distance | Center からの距離 ÷ 最大距離。**Center は Order の設定**（既定は並び全体の外接箱の中心、Point Macro も選べる） | なし |
| X / Y / Z | 外接箱の中の位置 | なし |

- Mask は要素を取り除かないので、Mask を時間で動かしても q・s・t_i は飛ばない。数が変わる（Count の Macro にキー、Merge の入力の数が変わる）と、Index の q は変わる（v3 の 1.1 節と同じ。数に依らない時刻には Stagger の Interval と段 s を使う）。

### 2.5 Morph の合わせ方

- **Match**（構造の入力）: By Order（q の順位で対応させる）/ Wrap（少ない方を番号で回す。要素が重なる）/ Shrink（多い方の余った要素は、相手のいちばん近い要素の位置へ縮んで消える）。既定は By Order。
- 補間する属性: 位置（線形）、向き（slerp）、大きさ・回転・透明度（線形）、色（OKLab で線形）。補間しないもの: ID・t_i・Source 番号（Morph の値が 0.5 を超えたら後の入力のものに切り替える）。
- 数が時間で変わる入力の Morph は、対応が飛ぶことがある（仕様）。

### 2.3 Modulator（値を動かす。シンセの LFO / ENV）

Modulator は「時刻 t と要素」から値を出し、ノードの数値の入力に深さ付きでつなぐ。1 つの Modulator を何か所にもつなげる。

| Modulator | 出力 |
|---|---|
| LFO | 周期の波（Sine / Triangle / Square / Saw / Random Hold）。Rate、Phase、要素ごとの Phase のずれ（q × Spread） |
| ENV | 時間の変化。Start からの Attack / Hold / Release とカーブ。要素ごとに開始を t_i にできる（時間で出現） |
| Stagger | 要素ごとの進み具合 r（v3 の 5.3 節: Drive Time / Progress、Timing Duration / Interval、Transition、Easing、Jitter）。出力は r か **1 − r（Remaining）** を選ぶ。出現（Reveal）は Remaining を「出現する前の姿」の深さにつなぐ（例: 大きさに深さ −100% → 出る前は大きさ 0）。要素の t_i（開始時刻）もここで決まる |
| Random | hash(ID, Seed)（2.4 節） |
| Noise | 位置と時刻で評価するノイズ |
| Field | Point Macro（ヌル）からの距離で 1 → 0 |
| Map | Layer のピクセルの明るさなど |
| Cascade | 段数 k（v3 の 5.2 節） |
| Macro | AE のマクロの値（キーフレーム・エクスプレッション） |
| Math | 2 つの Modulator の足し算・掛け算・最大・最小・反転 |

- Modulator 自身の入力（LFO の Rate など）にも Modulator をつなげる（シンセのモジュレーション）。ただし**輪にはできない**（エディターが輪を作らせない）。

## 3. 時間で動かす（キーフレームの代わり）

- AE のキーフレームを打てるのはマクロだけ。中の値を時間で動かす方法は 3 つ:
  1. ENV・LFO・Stagger をつなぐ（時間の形を決めて任せる）
  2. **マクロに出す**: エディターの値の上で「Expose」を選ぶと、空いているマクロに深さ 100% でつなぎ、名前を付ける。後は AE でキーを打つ
  3. マクロにエクスプレッション（ほかのレイヤーの値とつなぐ）
- これで「中の値にキーを打ちたいのに打てない」を避ける。ただし、AE のグラフエディターで中の値を直接見ることはできない（マクロの値として見る）。

## 4. 量・色・Order（v3 から引き継ぐ）

- Order（q と段 s）: v4 の 2.4 節（ID を加えた形）。v3 の 5.1 節の Pivot からの Distance は、Order の Center に置き換えた。
- 量の掛け方（足す・(1＋値) を掛ける・Tint を混ぜる・Source Shift）: v3 の 5.0 節の表を Modify ノードに使う。Modify に入る値は 2 節の「基準 ＋ Σ 深さ × 出力」。v3 の Stagger の「量 × (1 − r)」は、Stagger の出力 Remaining（1 − r）を深さでつなぐ形に置き換えた。
- 色と透明度の順番、Color Source（None なら白）・Color Blend、Gradient（補間 8 種と色相の回り方）: v3 の 6 節のまま。順番は「グラフの上流から下流へ」（Appearance と Modify のノードの順）。Blend Mode・Composite は Output ノード。Gradient は枠ではなく、Appearance のノードの中の帯。
- v3 の 1.3 節（時間で変えない選択）は、2 節の「構造の入力」に引き継いだ。

## 5. Emitter（配置 ＋ 時間のずらし ＋ 出た後の動き）

粒子（Emitter）の見た目を、前のフレームを使わずに作る。

| 部品 | ノード | 例 |
|---|---|---|
| どこから出るか | Generator（全部を最初から並べる） | 円の上、点 1 つ（Point）、レイヤーのアルファ |
| いつ出るか | Stagger（Interval で 1 つごとに何秒。毎秒 R 個 ＝ Interval 1/R。全部 0 秒なら爆発） | 毎秒 30 個 |
| 出た後どう動くか | **Motion**: 経過 age ＝ t − t_i（t_i より前は描かない） | 初速・重力・乱れ |
| いつ消えるか | Life（age が Life を超えたら描かない）、ENV で消え方 | 2 秒で薄くなって消える |
| 出し続けるか | Loop（同じ要素が周期ごとに生まれ直す。**Period**（秒）で指定し、t_i は周期の中に収める）。**Pre-roll**（秒）で、0 秒の時点ですでに湧き続けている状態から始められる | 少ない数で湧き続ける |

- **Loop の制約:** Life ≦ Period（1 つの要素を同時に 2 か所に描けないため。エディターが Life を Period に収める）。周期は秒で決まるので、要素の数を変えても周期は変わらない（数が多いほど密に湧く）。
- **Motion の式**（すべて age と要素番号だけで決まる）:
  - 位置 ＝ 出た位置 ＋ 初速 × age ＋ ½ × 重力 × age²
  - 空気抵抗は**速さに比例する抵抗だけ**にする（閉じた式があるのはこれだけ）: 位置 ＝ 出た位置 ＋ (初速 − 終端速度) × (1 − e^(−k·age)) / k ＋ 終端速度 × age（終端速度 ＝ 重力 ÷ k）
  - 初速 ＝ 向き（N＝外向き / T＝接線 / 指定の方向）× 速さ、要素ごとの乱れ（Spread・Speed Random、hash(ID)）
  - 乱れ（乱流）＝ Curl Noise を「乱流を足す前の位置」と age で評価した変位に、**age ＝ 0 で 0 になる立ち上がり**（Fade In）を掛けたもの（v2 の 4.5.3 節）
  - 風 ＝ 一定の力（重力と同じ式）
- **Motion の入力（初速・重力・風・空気抵抗・乱れの強さ）は、その要素が出た時刻 t_i の値を使う。** 今の t の値を使うと、マクロを動かしたときに、もう飛んでいる粒の軌跡がフレームごとに丸ごと変わってしまうため。
- **出た位置:** t_i の時刻の配置を読む（発生源が動くと軌跡が残る。v2 の 4.5.1 節）。要素ごとに違う時刻でグラフを評価し直すと重いので、
  - t_i で評価し直すのは、Motion より上流の **Generator と Transform（とそれにつながる Modulator・Macro）だけ**にする。
  - t_i はフレームの刻みに丸め、同じ時刻の評価はキャッシュする（時刻をキーにした純粋な関数なので、どのフレームから描いても同じ結果）。
- **作れないもの:** 粒どうしの衝突・跳ね返り・引き合い、途中の出来事で別の粒を出す。これらは前の状態が要るので、別のプラグインで扱う（決定のまま）。
- プリセット: Emitter（湧き出し）、Burst（爆発）、Fountain（噴水）、Rain（降らせる）、Disperse（配置が崩れて飛び散る）。

## 6. 描き方とレイヤー

- Render Mode（3D Layers / Fast）: v3 の 7.3 節の表のまま（3D Layers のコピーごとの色・複数の Source は要検証、既定は Fast）。
- Canvas（Fast の描く範囲、Auto と面積の上限）: v3 の 7.2 節のまま。グラフの Output ノードの設定にする。
- Layer 1〜8 は、複製元（Source）・Map・Layer Alpha の入力に共通で使う。どのノードがどの Layer を使うかはグラフデータ。

## 7. グラフデータの保存と取り消し

- グラフデータは Arbitrary Data 1 個。中身はバージョン番号付きの決まった形（ノード・つなぎ・名前・マクロのつなぎ方）で、保存・読み込み（Flatten / Unflatten）と、AE が求める比較・コピーを作る。
- **書き換えの経路（最大の要検証）:**
  - Effect Controls の Custom UI のイベントでは、`params[]` の Arbitrary Data を書き換え、change_flags を立てれば、AE が取り消しの履歴に入れる（SDK の ColorGrid の例と同じ）。
  - 別の窓（エディター）から書き換える経路は確かでない。案: (a) AEGP の `AEGP_SetStreamValue` で Arbitrary Data を設定する（ヘッダーの注記は Arbitrary Data に使えないとも読める）、(b) 窓は変更を溜め、Overview の Custom UI のイベントや AEGP の Idle Hook を経由して書く。P0 の最初に確かめ、だめなら「エディターを Effect Controls の Custom UI の大きな領域として描く」形に戻る。
- **ドラッグ中の扱い:** エディターでつまみを動かしている間は、エディターの中だけで画面を更新する（AE には書かない。プレビューはエディターの中の図）。離したときに 1 回だけグラフデータを書く。取り消しの履歴と Arbitrary Data の写しが、ドラッグのたびに積み上がらないようにするため。AE の画面にもドラッグ中の結果を出したいときの方法（一時的な値を sequence data に置いて描く、など）は要検証。
- **AE 側の取り消しとの同期:** グラフデータに版の番号を持つ。エディターは AE の Idle Hook で版の番号を比べ、AE 側で Ctrl+Z などにより変わっていたら、グラフを読み直す。
- MFR（複数のフレームを同時に描く）: 描画の側はグラフデータを読むだけ。書き換えは UI の主スレッドだけ。
- 大きさ: ノード数百でも数十 KB の見込み（推測）。Undo のたびに丸ごと写されるので、大きくなりすぎないよう P0 で測る。

## 9. 未決の事項（利用者の判断が要るもの）

1. マクロの数（数値 32・色 8・点 8 の案）。
2. エディターの入り口（別の窓か AE のパネルか）。
3. 初版のエディターを Windows だけにするか。**Windows だけにすると、Mac ではグラフを編集できない**（プリセットとマクロだけで使う）。
4. Morph で要素数が違うときの既定の合わせ方（2.5 節: By Order の案）。
5. 3D Layers でコピーごとの色や複数の Source ができなかったときの扱い（v3 から持ち越し）。
6. 今のハリボテ（v2 のパラメータ 409 個）は捨てて、v4 の約 70 個に作り直してよいか（パラメータの番号が変わるので、ハリボテで作ったプロジェクトは開けなくなる）。
