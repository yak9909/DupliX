# 複製プラグイン 設計案 v3（枠とエディター）

- 作成日：2026-11-27（同日夜に利用者の決定と 2 回目のレビューを反映して改訂）
- 位置付け：`複製プラグイン設計案_v2.md` の見直し。入力は `2026-11-27-wanted-features.md`（利用者の要望と決定）と、ハリボテ（`2026-11-27-v2-effect-controls.md`）で分かった AE の制約
- v2 から変えない原則：すべての値は「時刻と要素番号だけで決まる関数」（v2 の 0 節）。すべての値は AE のパラメータとして存在し、キーフレーム・エクスプレッションが使える（v2 の 7.1 節）。ただし表示する行を切り替える選択（Type など）は時間で変えない（1.3 節）
- AE 実機での確認が要る点には「要検証」と書いた

---

## 0. 結論（v2 からの変更点）

1. **「いくつでも足せるもの」はすべて同じ仕組みの枠（プール）にする。** Shape・Modifier・Gradient・Source の 4 種類。AE のパラメータは PARAMS_SETUP で数が決まり後から増やせないので、最初に枠を確保し、使っている枠だけを見せる。
2. **Shape を枠にし、Morph は「何番目の Shape の間にいるか」を表す 1 つの値にする。** Polar → Sphere → Grid のような連続した変化が、1 本のキーフレームで作れる。
3. **粒子（パーティクル）と複製を分ける。** v2 の Emission（順に生まれて飛ぶ粒）は DupliX 2 から外す。代わりに、**最初から並んでいるコピーが、時間とともに Order の順に出現する**（Modifier の Stagger を時刻で動かす。5.3 節）。粒子は別のプラグインで扱う。
4. **見た目（Appearance）を独立した段にする。** 透明度・色・描画モード・グラデーション・Order に沿った掛け合わせ。色と透明度が決まる順番は 6.0 節、量の掛け方は 5.0 節の表 1 つずつで定める。
5. **描き方は 2 つ（7.3 節）。** 今の DupliX の **3D Layers**（AE が本物の 3D レイヤーとして描く）を取り込み、自前の描画（**Fast**）と選べるようにする。
6. **混合のエディター（案 C）を自前で描く。** 構造（どの枠を使うか・順番・名前）は小さな独自データに、値は AE のパラメータに。Web の画面は使わない（重いため）。
7. **配置の中心（Pivot）とバッファの自動拡張（Canvas Auto）** を加える。

## 1. 全体の構造

```
Count（A × B × C、全体で 1 つ）
   │  要素番号 i → 整数座標 (a,b,c) → 正規化座標 (u,v,w)
   ▼
Layout ………… Shape 枠 1..N を Morph の値で補間（位置と向き T/N/B）。Pivot で大きさの中心を決める
   ▼
Flow …………… u / v / w をずらしてループ（v2 の 3 節のまま）
   ▼
Modifier × K … 上から順に: ドライバー（Wave・Noise・Random・Stagger・Cascade など）→ マスク → 各属性への量
   ▼
Appearance …… 色の出どころ・素材との混ぜ方・全体の透明度・描画モード
   ▼
Sources / Render … 複製元・時間・描き方（3D Layers / Fast）・Billboard・Global Transform・Canvas
```

### 1.1 Count は全体で 1 つのまま

v2 の 1.1 節を保つ。すべての Shape 枠が同じ A × B × C を解釈するので、Morph で要素番号が必ず一対一に対応する。

**Count を変えたときに保つもの:** 要素の乱数（hash(i, Seed)）と、Index・A・B・C の番号。**保たないもの:** 全体を 0〜1 に割り当てた値（5.1 節の q。例: Index の q ＝ i / (Count − 1)）と、形の中での位置（Grid の升目の間隔など）。数に依らない時刻で出したいときは、Stagger の Interval（5.3 節）を使う。

### 1.2 枠（プール）の共通の仕組み

| | Shape | Modifier | Gradient | Source |
|---|---|---|---|---|
| 枠の数（初版の目安） | 4 | 12 | 4 | 8 |
| 1 枠のパラメータ（目安） | 約 22 | 約 40 | 約 24（ストップ 8 個 × 色と位置 ＋ 設定 8） | 1 |

- 枠の中身はすべて AE のパラメータ。どの枠を使っているか・表示の順番・名前は独自データ（**構造データ**、Arbitrary Data 1 個）に持つ。構造データにはキーフレームを打つ対象を入れない（v2 の 7.1 節）。
- **使っているかどうかは値で決めない。** 使用中の印は構造データに持つ。
- 削除は「印を外して隠し、値を初期値に戻す」。複製は「値（キーフレームを含む）を空き枠に写す」（AEGP の Keyframe Suite、要検証）。並べ替えは構造データの順番だけを変える（キーフレームは枠と一緒に残る）。
- 合計は約 88 + 480 + 96 + 8 ＋ 共通 約 60 ≒ **730**。409 個で重くないことは確認済み（11/27）。730 で再確認する。
  **出荷後に足すパラメータは、Effect Controls でも末尾（Render の下）にしか並べられない**ので、枠は初版で多めに確保する（P0 で重さを測って決める）。
- 構造データの Arbitrary Data には `PF_ParamFlag_CANNOT_TIME_VARY` を付ける。エディターの表示状態（開いている枠、スクロール位置など）は構造データに入れず、sequence data に持つ（構造データを書き換えると取り消しの履歴が増え、描き直しが起きるため）。
- **隠す行の決まり:** 隠す可能性のある行には AE の角度パラメータ（ダイヤル付き）を使わない（隠してもダイヤルが残る。11/27 に確認）。度の数値スライダーにする。隠れた行にはスクリプトから値を入れられない（AE の制限）ので、エディターとスクリプトは先に表示してから値を入れる。

### 1.3 時間で変えない選択

表示する行や計算の種類を切り替える選択には `PF_ParamFlag_CANNOT_TIME_VARY` を付け、キーフレームを打てなくする。キーで変わると、表示する行が時間で入れ替わり、計算も飛ぶため。

- 対象: Shape の Type と Sampling、Pivot、Modifier の Type・Drive・Mask・Order・Along、Color Source・Color Blend・Blend Mode・Composite、Gradient の Interpolation・Hue Direction・Easing・Repeat、Render Mode、Canvas。
- 形を時間で変えたいときは、Shape を 2 つ作って Morph にキーを打つ（2.2 節）。

## 2. Shape 枠と Layout

### 2.1 Shape 枠

v2 の 2 節の Shape（Grid / Polar / Sphere / Path、Sampling Regular / Scatter）を 1 枠にする。

- 枠の中身: Type、Sampling、Seed Offset、Type ごとの設定（Grid Size・Brick、Inner / Outer Radius・Angle Range・Sides・Twist・Height、Sphere Radius・Shell Spacing・Latitude Range、Path・Row Spacing・Even Spacing）、枠ごとの Position / Rotation / Layout Scale（形全体を動かす）。
- **Layout Scale は配置の広がりだけを変え、コピーの大きさは変えない**（要望の 0 節）。コピーの大きさに効くのは Copy Scale（入口）・Modifier の Scale・Global Transform の Scale の 3 つ（5.0 節の掛け方）。
- 乱数: 入口の **Random Seed** が全体の種。枠の **Seed Offset** はそれに足す（既定 0）。
- 1 つ目の Shape 枠は常に使用中。入口には Shape 1 の Type と、**Type に応じた主な大きさ**（Grid: Grid Size X / Y、Polar・Sphere: Radius、Path: なし）を出す。同じパラメータを 2 か所に出すことはしない（入口に出した行は Shapes の中の Shape 1 には出さない）。Type は時間で変わらない（1.3 節）ので、入口の行も時間で変わらない。

### 2.2 Morph（連続した変化）

- **Morph** は 1 つの値（範囲 1〜使用中の Shape の数）。1.0 なら 1 番目の Shape、1.5 なら 1 番目と 2 番目の中間、2.0 なら 2 番目。順番は構造データの並び（エディターで並べ替える）。
- Shape が 1 つのときは Morph の行を隠す。
- **Shape の削除・並べ替えで、Morph にもう打ってあるキーの意味が変わる**（例: 2.0 が別の Shape を指す）。エディターと一覧は、Morph にキーかエクスプレッションがあるときに警告を出す。末尾への追加はもとの値の意味を変えないので警告しない。
- 位置は線形に、向き（T/N/B）は slerp で補間する（v2 の 4 節）。
- コピーごとのずれは Modifier の量「Morph」で足す（例: Stagger の Order = A で左から順に変わる）。足した結果は 1〜N に収める。
- 「散らばった形から格子へ集まる」は、Sampling を Scatter にした Shape から Grid の Shape への Morph で作る。

### 2.3 Pivot（大きさを変えるときの中心）

**全体で 1 つ**（Layout の共通設定、入口の近く）。形の大きさ（Grid Size・Radius・Layout Scale など）を変えたとき、動かない点を選ぶ。

| Pivot | 動かない点 |
|---|---|
| Center（既定） | 配置の中心（Grid は箱の中心、Polar・Sphere は円・球の中心、Path は経路の中点） |
| First / Last | 最初・最後の要素 |
| Index | 指定した番号の要素（Pivot Index） |
| Corner | 配置の外接箱の 9 点（左上・上・右上…） |
| Point | 任意の 3D 点（ヌルのピックウィップでつなぐ。v2 の 5.2 節の案 B と同じ） |

**定義（前の状態を使わない）:** 各 Shape 枠の **Position は Pivot の点を置く場所**とする。要素の位置 ＝ Position ＋（p − p_pivot）。p はその Shape の今の設定で計算した要素の位置、p_pivot は同じ設定で計算した Pivot の点。大きさを変えても p − p_pivot だけが伸び縮みするので、Pivot の点は Position に留まる。

- 仕様として起きること（不具合ではない）:
  - Pivot を切り替えると、Position の意味が変わるので配置が飛ぶ（Pivot は時間で変えない。1.3 節）。
  - Last・Index・Corner は Count と Scatter で決まる点なので、Count を変えると配置全体がずれる（その点が Position に来るよう全体が動く）。Count を動かすアニメーションでは Center か Point を使う。
- Morph の補間は、各 Shape で上の式を適用した後の位置どうしで行う。
- Order の Distance（5.1 節）が使う中心は、**Morph で補間した Pivot の点**（各 Shape の Position を Morph の重みで混ぜたもの）。

## 3. Flow

v2 の 3 節のまま（Offset / Speed / Speed Variance / Step、Boundary、Edge Fade）。全体で 1 つ。

## 4. 粒子（Emission）を外したこと

v2 の 4.5 節の Emission（生まれる時刻・寿命・初速・重力・乱流）と、v3 の最初の版の Emitter 枠は**採らない**（利用者の決定、11/27）。

- 理由: 粒子（順に生まれて飛んでいくもの）と複製（並べたものを動かすもの）は、使い方も設定も別物。1 つのエフェクトに入れると入口が複雑になる。
- 代わりに、**最初から全部並んでいるコピーを、時間とともに Order の順に出現させる**（5.3 節）。コピーの数・位置・順番は最初から決まっていて、時間で変わるのは「見えるかどうか・出現の途中の姿」だけ。
- 粒子の表現（生まれて飛ぶ、重力、乱流、寿命）は、将来の別プラグインで扱う。
- v2 にあった Age（経過時間）に関わる選択肢は、すべて外す（Wave の Along、Stagger の Order、Mask の Age Range、Time Offset の基準）。

## 5. Modifier 枠

1 枠 ＝ ドライバー 1 つ → マスク → 属性ごとの量（v2 の 5 節の考え方）。**上から順に**（構造データの並び）適用する。Cascade もほかの Type と同じく、並びの中の自分の位置で適用する。

| Type | ドライバー（要素ごとの値 d） | 設定 |
|---|---|---|
| Constant | d ＝ 1 | — |
| Wave | d ＝ sin(2π(Frequency × q ＋ Phase ＋ Speed × t)) | Along（5.1 節の q の選択肢）、Frequency、Phase、Speed |
| Noise | 位置で評価するノイズ（−1〜1） | Noise Scale、Evolution、Speed |
| Random | hash(i, Seed) を −1〜1 に | Seed |
| Stagger | 0 → 1 に進む（5.3 節）。Drive で Progress か Time を選ぶ | 5.3 節 |
| Cascade | 段数 k を使う（5.2 節） | Order（段を持つもの）、Limit |
| Map | レイヤーの明るさなど（v2 のまま） | Map Layer、Sample At、Channel |

- Mask: All / Index Range / Every N / Field / Stagger Range（別の Stagger 枠の進み具合 r が範囲内の要素だけ）。
- 量（0 のものは計算しない）: Position T / N / B、Shift A / B、Rotation、Scale、Opacity、Tint（色と Tint Amount）、Gradient、Time Offset、Source Shift、Morph。最後に Strength を掛ける。

### 5.0 量の掛け方（ここが唯一の定義）

ドライバーの値 d（Stagger は 1 − r、5.3 節）× Strength × 量 を、属性ごとに次のように効かせる。

| 属性 | 効かせ方 | 例 |
|---|---|---|
| Position T/N/B、Shift A/B、Rotation、Time Offset、Gradient、Morph | 足す | Position N +200 で外へ 200 px |
| Scale、Opacity | (1 ＋ 値) を掛ける。結果は 0 未満にしない | −100% で大きさ 0・見えない、+100% で 2 倍 |
| Tint | Tint の色を Tint Amount × d の割合で色 C に混ぜる | Tint Amount 100% で C が Tint の色に |
| Source Shift | 足して四捨五入し、Source の数で回す | 1 で次の Source に |

### 5.1 Order（共通の並び）

「要素を何の順に並べるか」。要素ごとに **q**（0〜1 の連続した値）と、段を持つものは **段 s**（整数）を返す。

| Order | q | 段 s | Count を変えたとき |
|---|---|---|---|
| Index | i / (Count − 1) | i | s は変わらない、q は変わる |
| A / B / C | a / (A − 1) など | a など | s は変わらない、q は変わる |
| Random | hash(i, Seed) | なし | 変わらない |
| Distance | Pivot の点からの距離 ÷ 全要素の最大距離 | なし | q は変わる |
| X / Y / Z | 外接箱の中での位置（0〜1） | なし | q は変わる |

- **Reverse**（逆順: q → 1 − q）を持つ。
- 要素が 1 つ（Count − 1 ＝ 0）のときは q ＝ 0。同じ値の要素は同じ q（同時に動く）。
- すべて今の時刻の値だけで決まる（前のフレームは使わない）。
- Wave の Along・Gradient の Along・Stagger の Order は、この q を使う。Cascade は段 s を使う（Index・A・B・C だけ選べる）。

### 5.2 Cascade（Order に沿って重ねる）

段 s ＝ k の要素に、1 段ごとの変化を k 回重ねる。

| 量 | k 段目の結果 |
|---|---|
| Opacity Step（例 80%） | 透明度 × 0.8^k（エコーのように奥ほど薄く） |
| Color Step（色） | 色 C × Color Step^k（チャンネルごとに掛ける） |
| Hue Step（度） | 色 C の色相を k × Hue Step 回す |
| Gradient Step | グラデーションの位置を k × Step 進める（6.2 節） |

- **Limit**（何段で止めるか）を持つ。k ＝ min(s, Limit)。
- Mask で対象を絞れる（例: Every N で 3 つおきに）。

### 5.3 Stagger（順にずらす。時間で出現する）

v2 の Stagger と「時間で出現」（要望の 7 節）を 1 つの Type にまとめる。要素ごとの進み具合 r（0〜1）を作り、量に **1 − r** を掛けて効かせる。つまり量は「**まだ進んでいない（出現する前の）姿**」を表す。

| 設定 | 意味 |
|---|---|
| Drive | **Time**（時刻で進む）/ **Progress**（Progress の値にキーを打って進める。v2 の Stagger） |
| Order | どの順に進むか（5.1 節の q） |
| Direction | Appear（量の姿 → 元の姿）/ Disappear（元の姿 → 量の姿。r を 1 − r に） |
| Timing（Time のとき） | **Duration**（全体を Start から Duration 秒の間に収める: t_i ＝ Start ＋ Duration × q）/ **Interval**（1 段ごとに Interval 秒: t_i ＝ Start ＋ Interval × s。段を持つ Order だけ。Count を変えても時刻が変わらない） |
| Start / Duration / Interval | 秒（**レイヤーの時間**。エフェクトが受け取る時刻と同じ） |
| Transition | 1 つの要素が出始めてから出切るまでの秒数 |
| Progress（Progress のとき） | 0〜100%。全体の進み（t_i の代わりに q と比べる） |
| Softness（Progress のとき） | 隣どうしが重なる幅（v2 のまま） |
| Easing | Linear / Ease In / Ease Out / Ease In Out |
| Jitter | 出る時刻の乱れ（秒）。要素ごとに hash(i, Seed) で 0〜Jitter 秒遅らせる |

- r ＝ Easing(clamp((t − t_i) / Transition, 0, 1))。**Transition が 0 なら段差**（t ≥ t_i で 1、それより前は 0）。要素が 1 つなら q ＝ 0 なので t_i ＝ Start。
- 「出現して、しばらくして消える」は Stagger を 2 枠（Appear と Disappear）使う。
- 透明度が 0 の要素は描かない（Fast の描画では飛ばす。3D Layers では AE にそのコピーを描かせない、要検証）。
- 「+ Add Modifier」に **Reveal**（出現）の項目を置く。中身は Stagger（Drive ＝ Time、Direction ＝ Appear、Opacity −100%、Scale −100%）を入れた枠で、すぐに出現の動きが見える。名前は Reveal と表示する。

## 6. Appearance（見た目）

全体で 1 つ（入口の次に置く）。色は「**どの色にするか（Color Source）**」と「**素材の色との混ぜ方（Color Blend）**」を別のパラメータに分ける。

### 6.0 コピーの色と透明度が決まる順番（ここが唯一の定義）

| 順 | 段 | 色 | 透明度 |
|---|---|---|---|
| 1 | 素材 | 素材の画素の色 | 素材の透明度 |
| 2 | Color Source | 要素の色 C の始まり: None なら**白**、Tint なら Tint Color、Gradient なら選んだ Gradient 枠のその要素の位置の色 | — |
| 3 | Modifier（上から順。Stagger・Cascade を含む） | C に Tint を混ぜる、Cascade の色、Gradient の位置を動かす | 5.0 節の掛け方 |
| 4 | Color Blend | C と素材の色を混ぜる: **Multiply**（既定）/ Replace（明るさは素材）/ Hue（色相だけ C）/ Overlay | — |
| 5 | Appearance | — | × Opacity（全体） |
| 6 | Blend Mode | コピー同士・背景と重ねる | |

- Color Source が None で Modifier も色を変えなければ、C は白のままで、Multiply は素材の色を変えない（v2 のハリボテと同じ見た目）。Modifier の Tint だけでも色が変わる（白に Tint を混ぜてから掛けるため）。
- Gradient の位置は、Gradient 枠の Along の q に、Modifier と Cascade の分を足してから色を引く。

### 6.1 透明度・色・描画モード

- **Opacity**（全体の透明度）。
- **Color Source**: None / Tint / Gradient。**Tint Color**（色）、**Gradient**（Gradient 枠の番号）。
- **Color Blend**: Multiply / Replace / Hue / Overlay。
- **Blend Mode**（コピー同士の重ね方）: Normal / Add / Screen / Multiply / Lighten / Darken。
  - Fast: Depth Sort がオンのとき、Normal は奥から順に重ねる。Add / Screen / Lighten / Darken / Multiply は順序に依らない。
  - **Copies Only で透明な背景に重ねたときの結果**を決める必要がある。案: Multiply・Screen などは「コピーどうしの重なり」にだけ効き、コピーと透明な背景の間は Normal と同じにする（AE のレイヤーの描画モードと同じ考え方）。P4 の前に、絵の例で確かめる。
  - 3D Layers での扱いは 7.3 節。
- **Composite**（元のレイヤーとの合成）: Copies Only / Behind / On Top。

### 6.2 Gradient 枠

- 枠の中身: **Along**（5.1 節の q の選択肢: Index / A / B / C / Random / Distance / X / Y / Z）、**Stops**（最大 8 個。各ストップは Color と Position。使うストップの数は構造データ）、**Interpolation**、**Hue Direction**、**Easing**（Linear / Smooth / Step）、**Repeat**（Clamp / Repeat / Mirror）、Offset、Scale。
- Along の q は 0〜1 の連続した値なので、A・B の位置や中心からの距離に沿った、なめらかなグラデーションになる。
- **Interpolation（補間の方法）:** RGB / Linear RGB / HSV / HSL / Lab / OKLab / OKLCH / Step（補間しない）。色相を持つもの（HSV / HSL / OKLCH）は **Hue Direction**（Shorter / Longer / Increasing / Decreasing）を選べる。
- 使い方: Appearance の Color Source を Gradient にして、Gradient 枠を 1 つ選ぶ。Cascade の Gradient Step、Modifier の量 Gradient がその位置を動かす。
- ストップの位置・色はすべて AE のパラメータ（キーフレーム可）。エディターでは帯の上でストップを動かす。

## 7. Sources と Render

### 7.1 Sources

ハリボテのまま（Source 1〜8、Assign: Sequential / Random / By A / By B、Time Mode / Offset / Quantize）。**Copy Scale**（入口）はコピーの大きさの基準（素材の元の大きさ × Copy Scale × 5.0 節の Scale × Global Transform の Scale）。

### 7.2 Render

v2 の 6 節（Billboard、Depth Sort、Depth Fade、Global Transform）に加えて:

- **Canvas**（描く範囲、Fast だけ）: Layer（レイヤーの範囲で切る、既定）/ **Auto**（コピー全部が入るよう自動で広げる）。Auto には **Margin**（ぼかしなどの余白、px）を持つ。
  - 計算: PreRender で全コピーの画面上の外接箱を求め、出力の `result_rect` をそれに合わせる。外接箱も時刻と番号だけで決まる（前のフレームは使わない）。
  - **上限は面積で持つ。** 1 辺 30000 px までは AE が受け付けても、32 bpc では 1 枚およそ 14 GB になるので使えない。上限（例: 1 億画素）を超えるときは、レイヤーの中心のまわりで上限に収まるよう切る。上限の値は P0 でメモリと速さを測って決める。
  - Comp（コンプの範囲）は後回し。レイヤーの変形を AEGP で読む必要があるため。

### 7.3 描き方（Render Mode）: 3D Layers と Fast

今の DupliX の 2 つの描き方を取り込む（利用者の決定、11/27）。**Render Mode は入口に出す**（選んだ描き方で使える機能が大きく変わるため）。

| | 3D Layers | Fast |
|---|---|---|
| 描く人 | AE（コピーを本物の 3D レイヤーとして。今の DupliX の差し込みと軽量化の技術） | DupliX（全コピーを 1 枚の絵に。今の DupliX の Fast (2D) の技術、GPU） |
| ライト・影・被写界深度・ほかのレイヤーとの前後と交差 | 本物と同じ | なし（1 枚の 2D レイヤー） |
| 位置・回転・大きさ・透明度（Layout・Modifier・Stagger） | ○（今の DupliX で透明度まで実績あり） | ○ |
| コピーごとの色（Tint・Gradient・Cascade の色・Color Blend） | **要検証**（AE はコピーを同じレイヤーの絵から描く。コピーごとに色を変えるには、差し込みで色を掛けるか、色ごとに絵を分ける必要がある） | ○ |
| Blend Mode（コピー同士） | レイヤー自身の描画モードに従う（AE の 3D の重ね方）。コピーごとには変えられない見込み（推測） | ○ |
| 複数の Source | **要検証**（今の DupliX は自分のレイヤーしか複製しない。ほかのレイヤーの絵をコピーに使う差し込みが要る） | ○（ハリボテで実装済み） |
| Canvas | 効かない（AE が描く） | ○ |
| 壊れやすさ | SDK の外（AE の内部）への差し込みに頼るので、AE の版が変わると直しが要る（今の DupliX と同じ。推測ではなく、今までの開発で実際に AE の内部の関数の番地を使っている） | SDK の範囲 |

- **既定は Fast**（すべての機能が使え、AE の版に左右されにくい）。本物の 3D の重なりや影が要るときに 3D Layers を選ぶ。
- 3D Layers でできない設定は、その描き方のときに灰色にし、Overview に理由を短く出す（例: 「Color: Fast only」）。
- どちらでも、位置・順番・出現の計算（Layout・Modifier・Order）は同じコードを使い、描き方だけが違うようにする。
- 今の DupliX（別のエフェクト）は、DupliX 2 の 3D Layers が今の DupliX の機能をすべて満たすまで残す。満たしたら、今の DupliX を DupliX 2 に置き換えるかを利用者が決める。

## 8. エディター（案 C、自前で描く）

### 8.1 分担

| 持つ場所 | 中身 |
|---|---|
| AE のパラメータ（枠） | すべての値（キーフレーム・エクスプレッション・ピックウィップ可） |
| 構造データ（Arbitrary Data 1 個、`CANNOT_TIME_VARY`） | 枠の使用中の印、表示の順番、名前、Morph の順番、Gradient のストップの数 |
| sequence data | エディターと一覧の表示状態（開いている枠など。取り消しの履歴に入れない） |
| エディター | 構造データの編集と、値の見やすい編集（帯のグラデーション、Shape の図、Morph の並び、Stagger の時間の図）。値は AE のパラメータに書き込む |

### 8.2 形

- **自前で描く。Web の画面（HTML・CEP・UXP・埋め込みブラウザー）は使わない**（重いため。利用者の決定、11/27）。
- 入り口は 2 つの案があり、P0 で決める:
  - AE のパネル（AEGP のパネルの仕組み、`AE_GeneralPlugPanels.h`。AE が OS の窓を渡し、中身はプラグインが OS の描画 API で描く。AE の作業画面にドッキングできる）。パネルの登録には AEGP の plugin id が要る。エフェクトの .aex から登録できるか、別の AEGP プラグインが要るかは要検証
  - Effect Controls の **Open Editor** ボタンで開く別の窓（Trapcode の Designer と同じ入り口）
- 自前で描くので、Windows と Mac で描画の作りが 2 通り要る。**初版は Windows だけ**とするかは利用者が決める（10 節）。
- 窓での変更は AE の取り消し（Ctrl+Z）1 回分にまとめる（AEGP の Undo Group）。
- 窓から AE のパラメータを書き換える処理は、AE の主スレッドで動かす必要がある（推測。AEGP の呼び出しは主スレッドの前提）。窓は依頼を溜め、主スレッドの処理（AEGP の Idle Hook など）でまとめて書く形を P0 で確かめる。
- 窓を開いたまま、エフェクトの削除・レイヤーの削除・別のレイヤーの選択・取り消しが起きたときに、窓が古い対象に書き込まないこと（追従するか閉じる）を P0 で確かめる。
- エディターがなくても使える: Effect Controls の Custom UI（Overview・枠の一覧）で、枠の追加・削除・並べ替えはできる。

### 8.3 Effect Controls の構成（v3）

```
DupliX 2
├ Overview（Custom UI: 配置の図・要約・Open Editor）
├ 入口: Render Mode、Shape 1 の Type、Shape 1 の主な大きさ（Type に応じて）、Count A / B / C、Copy Scale、Pivot、Morph（Shape が 2 つ以上のときだけ）、Random Seed
├ Appearance（開）: Opacity、Color Source、Tint Color、Gradient、Color Blend、Blend Mode、Composite
├ Shapes（閉）: 一覧（Custom UI）＋使用中の Shape 枠
├ Flow（閉）
├ Modifiers（開）: 一覧＋使用中の Modifier 枠（Stagger・Reveal・Cascade もここ）
├ Gradients（閉）: 一覧＋使用中の Gradient 枠
├ Sources（開）: 一覧＋Source 1〜8
└ Render（閉）: Canvas、Billboard、Depth、Global Transform
```
