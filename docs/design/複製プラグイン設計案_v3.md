# 複製プラグイン 設計案 v3（枠とエディター）

- 作成日：2026-11-27
- 位置付け：`複製プラグイン設計案_v2.md` の見直し。入力は `2026-11-27-wanted-features.md`（利用者の要望）と、ハリボテ（`2026-11-27-v2-effect-controls.md`）で分かった AE の制約
- v2 から変えない原則：すべての値は「時刻と要素番号だけで決まる関数」（v2 の 0 節）。すべての値は AE のパラメータとして存在し、キーフレーム・エクスプレッションが使える（v2 の 7.1 節）
- AE 実機での確認が要る点には「要検証」と書いた

---

## 0. 結論（v2 からの変更点）

1. **「いくつでも足せるもの」はすべて同じ仕組みの枠（プール）にする。** Shape・Emitter・Modifier・Gradient・Source の 5 種類。AE のパラメータは PARAMS_SETUP で数が決まり後から増やせないので、最初に枠を確保し、使っている枠だけを見せる。
2. **Shape を枠にし、Morph は「何番目の Shape の間にいるか」を表す 1 つの値にする。** Polar → Sphere → Grid のような連続した変化が、1 本のキーフレームで作れる（要望 2）。
3. **Emitter を枠にする。** Emitter ごとに発生元の Shape と発生の設定を持つ（要望 1）。
4. **見た目（Appearance）を独立した段にする。** 透明度・色・描画モード・グラデーション・Order に沿った掛け合わせ（要望 5）。色と透明度が決まる順番は 6.0 節の表 1 つで定める。グラデーションは補間の方法を選べる枠にする。
5. **混合のエディター（案 C）。** 構造（どの枠を使うか・順番・名前・つなぎ）は小さな独自データに、値は AE のパラメータに。Effect Controls には入口と使っている枠だけを出す（要望 3）。
6. **配置の中心（Pivot）とバッファの自動拡張** を Layout の共通設定に加える（要望 4）。

## 1. 全体の構造

```
Count（A × B × C、全体で 1 つ）
   │  要素番号 i → 整数座標 (a,b,c) → 正規化座標 (u,v,w)
   ▼
Layout ………… Shape 枠 1..N を Morph の値で補間（位置と向き T/N/B）。Pivot で大きさの中心を決める
   ▼
Flow …………… u / v / w をずらしてループ（v2 の 3 節のまま）
   ▼
Emission ……… 任意。Emitter 枠 1..M（Shape 枠を発生元にする）
   ▼
Modifier × K … ドライバー → マスク → 各属性への量（v2 の 5 節）
   ▼
Appearance …… 透明度・色・グラデーション・Order の掛け合わせ・描画モード
   ▼
Sources / Render … 複製元・時間・Billboard・Global Transform・バッファ
```

### 1.1 Count は全体で 1 つのまま

v2 の 1.1 節を保つ。すべての Shape 枠が同じ A × B × C を解釈するので、Morph で要素番号が必ず一対一に対応する。Emission を使うときの扱いは 4 節。

### 1.2 枠（プール）の共通の仕組み

| | Shape | Emitter | Modifier | Gradient | Source |
|---|---|---|---|---|---|
| 枠の数（初版の目安） | 4 | 4 | 8 | 4 | 8 |
| 1 枠のパラメータ（目安） | 約 22 | 約 28 | 約 40 | 約 20（ストップ 8 個） | 1 |

- 枠の中身はすべて AE のパラメータ。どの枠を使っているか・表示の順番・名前は独自データ（**構造データ**、Arbitrary Data 1 個）に持つ。構造データにはキーフレームを打つ対象を入れない（v2 の 7.1 節）。
- **使っているかどうかは値で決めない。** v2 のハリボテでは「Type = None なら未使用」としたが、Type にキーフレームを打たれると、未使用かどうかが時間で変わってしまう。使用中の印は構造データに持つ。
- 削除は「印を外して隠し、値を初期値に戻す」。複製は「値（キーフレームを含む）を空き枠に写す」（AEGP の Keyframe Suite、要検証）。並べ替えは構造データの順番だけを変える（キーフレームは枠と一緒に残る）。
- 合計は約 88 + 112 + 320 + 80 + 8 ＋ 共通 約 60 ≒ **670**。409 個で重くないことは確認済み（11/27）。670 で再確認する。
  **出荷後に足すパラメータは、Effect Controls でも末尾（Render の下）にしか並べられない**ので、枠は初版で多めに確保する（P0 で重さを測って決める）。
- 構造データの Arbitrary Data には `PF_ParamFlag_CANNOT_TIME_VARY` を付ける（キーフレームを打てない）。エディターの表示状態（開いている枠、
  スクロール位置など）は構造データに入れず、sequence data に持つ（構造データを書き換えると取り消しの履歴が増え、描き直しが起きるため）。
- **時間で変えてはいけない値**（要素の割り当てを決めるもの）には `PF_ParamFlag_CANNOT_TIME_VARY` を付ける: Emitter の Share（4 節）。
  Count にはキーフレームを打てるが、「Count を増やしても前からある要素の割り当て・位置は変わらない」ことを守る（v2 の 2.1 節の Scatter と同じ）。
- **隠す行の決まり:** 隠す可能性のある行には AE の角度パラメータ（ダイヤル付き）を使わない（隠してもダイヤルが残る。11/27 に確認）。度の数値スライダーにする。隠れた行にはスクリプトから値を入れられない（AE の制限）ので、エディターとスクリプトは先に表示してから値を入れる。

## 2. Shape 枠と Layout

### 2.1 Shape 枠

v2 の 2 節の Shape（Grid / Polar / Sphere / Path、Sampling Regular / Scatter）を 1 枠にする。

- 枠の中身: Type、Sampling、Seed Offset、Type ごとの設定（Grid Size・Brick、Inner / Outer Radius・Angle Range・Sides・Twist・Height、Sphere Radius・Shell Spacing・Latitude Range、Path・Row Spacing・Even Spacing）、**Pivot**（2.3 節）、枠ごとの Position / Rotation / Layout Scale（形全体を動かす）。
- **Layout Scale は配置の広がりだけを変え、コピーの大きさは変えない**（要望の 0 節）。コピーの大きさに効くのは Copy Scale（入口）・Modifier の Scale・Global Transform の Scale の 3 つで、すべて掛け算。
- 乱数: 入口の **Random Seed** が全体の種。枠の **Seed Offset** はそれに足す（既定 0。枠ごとに別の並びにしたいときだけ触る）。
- 1 つ目の Shape 枠は常に使用中。入口には Shape 1 の Type と、**Type に応じた主な大きさ**（Grid: Grid Size X / Y、Polar・Sphere: Radius、Path: なし）を出す。同じパラメータを 2 か所に出すことはしない（入口に出した行は Shapes の中の Shape 1 には出さない）。
- 構造データに Shape 枠ごとの **In Morph**（Morph の並びに入れるか）を持つ。Emitter の発生元にだけ使う Shape は In Morph をオフにする。

### 2.2 Morph（連続した変化）

- **Morph** は 1 つの値（範囲 1〜In Morph の Shape の数）。1.0 なら 1 番目の Shape、1.5 なら 1 番目と 2 番目の中間、2.0 なら 2 番目。順番は構造データの並び（エディターで並べ替える）。
- In Morph の Shape が 1 つのときは Morph の行を隠す。
- **Shape の追加・削除・並べ替えで、Morph にもう打ってあるキーの意味が変わる**（例: 2.0 が別の Shape を指す）。エディターと一覧は、Morph にキーかエクスプレッションがあるときに警告を出す。末尾への追加はもとの値の意味を変えないので警告しない。
- 位置は線形に、向き（T/N/B）は slerp で補間する（v2 の 4 節）。
- コピーごとのずれは Modifier の量「Morph」で足す（例: Stagger の Order = A で左から順に変わる）。足した結果は 1〜N に収める。
- v2 の Target Shape・Morph Amount は廃止する（Shape 枠が 2 つ、Morph が 1→2 と同じ）。

### 2.3 Pivot（大きさを変えるときの中心）

形の大きさ（Grid Size・Radius など）を変えたとき、動かない点を選ぶ。

| Pivot | 動かない点 |
|---|---|
| Center（既定） | 配置の中心（Grid は箱の中心、Polar・Sphere は円・球の中心、Path は経路の中点） |
| First / Last | 最初・最後の要素 |
| Index | 指定した番号の要素（Pivot Index） |
| Corner | 配置の外接箱の 9 点（左上・上・右上…） |
| Point | 任意の 3D 点（ヌルのピックウィップでつなぐ。v2 の 5.2 節の案 B と同じ） |

**定義（前の状態を使わない）:** 枠の **Position は Pivot の点を置く場所**とする。要素の位置 ＝ Position ＋（p − p_pivot）。p はその Shape の今の設定で計算した要素の位置、p_pivot は同じ設定で計算した Pivot の点。大きさを変えても p − p_pivot だけが伸び縮みするので、Pivot の点は Position に留まる。すべて今の時刻の値だけで決まる。

- Morph の補間は、各 Shape で上の式を適用した後の位置どうしで行う。
- Order の Distance（5.1 節）が使う中心は、**Morph で補間した Pivot の点**（各 Shape の Position を Morph の重みで混ぜたもの）。

## 4. Emitter 枠（複数の Emission）

v2 の 4.5 節の Emission を 1 枠にする。

- 枠の中身: **発生元の Shape 枠**（番号で選ぶ）、**Share**（要素の取り分の重み、`CANNOT_TIME_VARY`）、Start / Duration / Rate / Birth Jitter、Life / Life Random / Loop、Velocity / Velocity Random / Direction / Spread、Gravity / Wind / Air Resistance、乱流（Amount / Scale / Complexity / Evolution / Flow Speed / Fade In）。
- **要素数は常に Count（A × B × C）。** Emitter を使っても 1.1 節は変えない。
- **要素の割り当て:** 要素 i がどの Emitter のものかは、i と Random Seed から作る乱数を Share の累積に当てて決める。
  - i だけで決まるので時刻に依らない。
  - Count を増やしても、前からある要素の割り当ては変わらない。番号を区切る方式だと Count の変更で境目が動くので、使わない。
  - Share は `CANNOT_TIME_VARY` なので、割り当てが時間で変わることはない。
- 発生元の Shape 枠は、自分の A × B × C の並び（要素 i の (a,b,c)）で発生位置を決める。要素は Shape の全体に散らばるので、Emitter ごとに Shape の一部だけから湧くことはない。
- Emitter の発生元の Shape 枠の値（位置・向き・初速・色など）は、v2 と同じく**生まれた時刻の値**を読む。
- **素材の選び方:** Emitter 枠には Source を持たせない。Emitter ごとに素材を変えたいときは、Sources の Assign で **By Emitter** を選ぶ（選び方は Assign の 1 か所に限る）。
- **Morph との関係:** Emission を使うと、Layout（Shape の Morph）は発生元の位置を決める役になる。
  - 「飛び散った形から格子へ集まる」（v2 の 4.5.4 節）は、Emitter 枠の **Gather** で作る。Gather は 0〜100% で、Emission の位置から、指定した Shape 枠の位置へ補間する。
  - 行き先の Shape も Count で並ぶので、要素は一対一に対応する。
  - Emitter の結果を Morph の並びの 1 つとして扱う案は採らなかった（10 節で利用者に確認する）。

## 5. Modifier 枠

v2 の 5 節のまま（Type: Wave / Noise / Random / Stagger / Map / Constant、Mask、各属性への量、Strength）。変更点:

- Type に **Cascade**（5.2 節）を加える。
- 量に **Morph**（2.2 節の値に足す）、**Gradient**（Appearance のグラデーションの位置を動かす）を加える。Opacity・Tint は Appearance 側と同じ掛け方にそろえる（6 節）。
- Order の選択肢（Index / A / B / C / Random / Distance / Age / Emitter）を Stagger・Cascade・グラデーションで共通にする。

### 5.1 Order（共通の並び）

「要素を何の順に並べるか」。Index（番号）、A・B・C（格子の位置）、Random（Seed で決まる順）、Distance（Pivot からの距離）、Age（Emission の経過時間）、Emitter（Emitter の番号）。並びは時刻と要素番号だけで決まる（Distance と Age は時刻の関数。前のフレームは使わない）。

### 5.2 Cascade（Order に沿って重ねる、要望 5.3）

Order で並べた k 番目（0 始まり）の要素に、1 段ごとの変化を k 回重ねる。

| 量 | k 番目の結果 |
|---|---|
| Opacity Step（例 80%） | 透明度 × 0.8^k（エコーのように奥ほど薄く） |
| Color Step（色） | 色 × Color Step^k（チャンネルごとに掛ける） |
| Hue Step（度） | 色相を k × Hue Step 回す |
| Gradient Step | グラデーションの位置を k × Step 進める（6.2 節） |

- k は Order の順位（同じ値の要素は同じ順位）。Count が大きいと 0.8^k は 0 に近づくので、**Limit**（何段で止めるか）を持つ。
- Mask で対象を絞れる（例: Every N で 3 つおきに）。

## 6. Appearance（見た目、要望 5）

全体で 1 つ（入口の次に置く）。色は「**どの色にするか（Color Source）**」と「**素材の色との混ぜ方（Color Blend）**」を別のパラメータに分ける。

### 6.0 コピーの色と透明度が決まる順番（ここが唯一の定義）

| 順 | 段 | 色 | 透明度 |
|---|---|---|---|
| 1 | 素材 | 素材の画素の色 | 素材の透明度 |
| 2 | Color Source | 要素の色 C を決める: None / Tint（Tint Color）/ Gradient（選んだ Gradient 枠の、その要素の位置の色） | — |
| 3 | Modifier | C に Tint（量 Tint Amount で混ぜる）、Gradient の位置をずらす量 | Opacity の量を掛ける |
| 4 | Cascade | C に Color Step^k を掛ける、色相を k × Hue Step 回す、Gradient の位置を k × Step 進める | × Opacity Step^k |
| 5 | Color Blend | C と素材の色を混ぜる: Multiply / Replace（明るさは素材）/ Hue（色相だけ C）/ Overlay | — |
| 6 | Appearance | — | × Opacity（全体） |
| 7 | Blend Mode | コピー同士・背景と重ねる | |

- 透明度の段はすべて掛け算、Gradient の位置の段はすべて足し算（位置を足してから色を引く）。

### 6.1 透明度・色・描画モード

- **Opacity**（全体の透明度）。
- **Color Source**: None / Tint / Gradient。**Tint Color**（色）、**Gradient**（Gradient 枠の番号）。
- **Color Blend**: Multiply / Replace / Hue / Overlay（Color Source が None なら効かない）。
- **Blend Mode**（コピー同士の重ね方）: Normal / Add / Screen / Multiply / Lighten / Darken。
  - コピーは DupliX が自分で描くので、AE の 3D の描画方式とは関係しない（10 節の 2 で 3D の描き方を決めるまでは 2D の描画で考える）。
  - Depth Sort がオンのとき、Normal は奥から順に重ねる。Add / Screen / Lighten / Darken は順序に依らない。Multiply も順序に依らない。
  - **Copies Only で透明な背景に重ねたときの結果**を決める必要がある。案: Multiply・Screen などは「コピーどうしの重なり」にだけ効き、コピーと透明な背景の間は Normal と同じにする（AE のレイヤーの描画モードと同じ考え方）。P4 の前に、絵の例で確かめる。
- **Composite**（元のレイヤーとの合成）: Copies Only / Behind / On Top。

### 6.2 Gradient 枠

- 枠の中身: **Along**（Order と同じ選択肢。5.1 節）、**Stops**（最大 8 個。各ストップは Color と Position。使うストップの数は構造データ）、**Interpolation**、**Hue Direction**、**Easing**（Linear / Smooth / Step）、**Repeat**（Clamp / Repeat / Mirror）、Offset。
- **Interpolation（補間の方法）:** RGB / Linear RGB / HSV / HSL / Lab / OKLab / OKLCH / Step（補間しない）。色相を持つもの（HSV / HSL / OKLCH）は **Hue Direction**（Shorter / Longer / Increasing / Decreasing）を選べる。
- 使い方: Appearance の Color Source を Gradient にして、Gradient 枠を 1 つ選ぶ。Cascade の Gradient Step、Modifier の量 Gradient がその位置を動かす。
- ストップの位置・色はすべて AE のパラメータ（キーフレーム可）。エディターでは帯の上でストップを動かす。

## 7. Sources と Render

### 7.1 Sources

ハリボテのまま（Source 1〜8、Assign: Sequential / Random / By A / By B、Time Mode / Offset / Quantize）。Assign に **By Emitter** を加える。**Copy Scale**（入口）はコピーの大きさの基準（素材の元の大きさ × Copy Scale × ほかの倍率）。

### 7.2 Render

v2 の 6 節（Billboard、Depth Sort、Depth Fade、Global Transform）に加えて:

- **Canvas**（描く範囲）: Layer（レイヤーの範囲で切る、既定）/ **Auto**（コピー全部が入るよう自動で広げる）。Auto には **Margin**（ぼかしなどの余白、px）を持つ。
  - 計算: PreRender で全コピーの画面上の外接箱を求め、出力の `result_rect` をそれに合わせる。外接箱も時刻と番号だけで決まる（前のフレームは使わない）。
  - **上限は面積で持つ。** 1 辺 30000 px までは AE が受け付けても、32 bpc では 1 枚およそ 14 GB になるので使えない。上限（例: 1 億画素）を超えるときは、レイヤーの中心のまわりで上限に収まるよう切る。上限の値は P0 でメモリと速さを測って決める。
  - Comp（コンプの範囲）は後回し。レイヤーの変形を AEGP で読む必要があり、その値はレイヤーの変形のキーやエクスプレッションに依存するため。
  - 3D（AE のカメラに乗せる描き方）では、AE が 3D レイヤーとして描くので Canvas は効かない（今の DupliX の 3D Layers と同じ考え方。要検証）。

## 8. エディター（案 C）

### 8.1 分担

| 持つ場所 | 中身 |
|---|---|
| AE のパラメータ（枠） | すべての値（キーフレーム・エクスプレッション・ピックウィップ可） |
| 構造データ（Arbitrary Data 1 個、`CANNOT_TIME_VARY`） | 枠の使用中の印、表示の順番、名前、Shape の In Morph と Morph の順番、Gradient のストップの数 |
| sequence data | エディターと一覧の表示状態（開いている枠など。取り消しの履歴に入れない） |
| エディター | 構造データの編集と、値の見やすい編集（帯のグラデーション、Shape の図、Morph の並び）。値は AE のパラメータに書き込む |

### 8.2 形

- Effect Controls の先頭（Overview）に **Open Editor** のボタンを置き、別の窓を開く（Trapcode の Designer と同じ入り口）。窓の作り（自前の描画か、埋め込みの Web 画面か）は要検証。
- 窓での変更は AE の取り消し（Ctrl+Z）1 回分にまとめる（AEGP の Undo Group）。
- 窓から AE のパラメータを書き換える処理は、AE の主スレッドで動かす必要がある（推測。AEGP の呼び出しは主スレッドの前提）。窓は依頼を溜め、主スレッドの処理（AEGP の Idle Hook など）でまとめて書く形を P0 で確かめる。
- 窓を開いたまま、エフェクトの削除・レイヤーの削除・別のレイヤーの選択・取り消しが起きたときに、窓が古い対象に書き込まないこと（追従するか閉じる）を P0 で確かめる。
- エディターがなくても使える: Effect Controls の Custom UI（Overview・枠の一覧）で、枠の追加・削除・並べ替えはできる。

### 8.3 Effect Controls の構成（v3）

```
DupliX 2
├ Overview（Custom UI: 配置の図・要約・Open Editor）
├ 入口: Shape 1 の Type、Shape 1 の主な大きさ（Type に応じて）、Count A / B / C、Copy Scale、Morph（In Morph の Shape が 2 つ以上のときだけ）、Random Seed
├ Appearance（開）: Opacity、Color Source、Tint Color、Gradient、Color Blend、Blend Mode、Composite
├ Shapes（閉）: 一覧（Custom UI）＋使用中の Shape 枠
├ Flow（閉）
├ Emitters（閉）: 一覧＋使用中の Emitter 枠
├ Modifiers（開）: 一覧＋使用中の Modifier 枠
├ Gradients（閉）: 一覧＋使用中の Gradient 枠
├ Sources（開）: 一覧＋Source 1〜8
└ Render（閉）: Canvas、Billboard、Depth、Global Transform
```

## 9. 実装の順番（v2 の 11 節の見直し）

| 段階 | 内容 | 終わりの条件 |
|---|---|---|
| P0 | SDK の検証（v2 の P0 に加え）: Arbitrary Data の構造データと Undo、枠の複製（キーフレームの写し）、670 パラメータの重さと枠の数、Canvas Auto の result_rect と面積の上限、エディターの窓（主スレッドでの書き込み、削除・選択の変更・取り消しへの追従） | 構造データを書き換えても取り消し 1 回で戻る |
| P1 | 枠の仕組み（構造データ・一覧の Custom UI・表示）、Shape 枠 1 つの Grid / Polar と Pivot、Count、Copy Scale、Canvas、Sources（済み） | 「螺旋」が作れ、Grid Size を変えても Pivot が動かない |
| P2 | Shape 枠 2 つ以上と Morph、Sphere・Scatter | Polar → Sphere → Grid を 1 本のキーフレームで |
| P3 | Modifier（Wave / Noise / Random / Constant / Stagger）、Mask、Order | 「同心円縞」「指定番号だけ変える」 |
| P4 | Appearance（Opacity・Color Source / Color Blend・Blend Mode）、Gradient 枠（補間 8 種）、Cascade | 「奥ほど薄いエコー」「OKLCH の虹」 |
| P5 | Flow、Path | 「リングがループ」「パスに沿って移動」 |
| P6 | Emitter 枠（複数）、Gather | 「左右から湧く」「飛び散った形から格子へ集まる」 |
| P7 | エディター | 枠の並べ替え・Gradient の帯の編集 |
| P8 | 3D 描画とカメラ、Billboard、Field、Map | v2 の P1・P6 の作例 |

v2 では 3D とカメラを P1 にしていたが、v3 では 2D の描画で枠の仕組みと見た目を先に固め、3D（今の DupliX の 3D Layers・Fast の技術の取り込み）を後に回す。

## 10. 未決の事項（利用者の判断が要るもの）

3. エディターの窓の作り（8.2 節）。
4. 枠の数（1.2 節の目安）。
