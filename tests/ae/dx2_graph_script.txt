# the editor scripts of tests/ae/dx2_graph.jsx, run by the effect through the editor when Random Seed is set
== seed 1 ==
# comp B: a circle of 6, its Radius exposed (Macro 1: nothing is linked after "clear"), turned 45 degrees, 50%
clear
add Circle 40 60 as c
add Modify 200 60 as m
add Output 360 60 as o
wire c m
wire m o
set c count 6
expose c radius
set m rotZ 45
set m opacity -50
== seed 2 ==
# comp C: the default grid (Int Macro 1, Macro 2-3 in use) with a second layer in z; Spacing Z exposed lands on Macro 1, a row
# AE hides until the graph uses it (the user's first Expose on a new instance)
set 1 countZ 2
set 1 spacingZ 80
expose 1 spacingZ
# design v5 P1.5e: the grid copied for yourself (a group in the graph data), Spacing Y from an Expression node, a math
# node with an operator (saved with op=); the render must still match dxg5_test's evaluation of this script
copygroup g
connectexpr g sy
formula g.sy m2 / 2
add math 0 0 as m
op m sin
== seed 3 ==
# comp D: a circle of 7 not wired. run_dx2_graph.ps1 then drives the editor's window with the mouse: drags from the
# circle's output (250, 418) to the Output's input (510, 148), clicks the circle's Count (200, 438) and types 9
add Circle 20 330 as c
set c count 7
== seed 4 ==
# comp E: what the Overview's Circle button does (the same function), not an editor script
uipreset Circle
